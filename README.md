# Titanic-Exploratory-Data-Analysis

# Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Titanic passenger dataset using Python. The aim is to investigate passenger characteristics and identify patterns associated with passenger survival during the Titanic disaster. 
The analysis explores passenger ticket fares, passenger classes, family relationships, and embarkation ports. Data analysis and visualization techniques are used to uncover patterns, interpret findings and communicate insights from the dataset.

# Objectives
- Understand the titanic dataset and its key features.
- Clean and prepare the data for analysis.
- Explore passenger characteristics and survival patterns.
- Identify relationships between passenger survival and other variables.
- Use visualiuzations to communicate findings.
- Present insights and recommendations based on the findings.

# Dataset Overview
The dataset contains information about passengers aboard  the Titanic, including their age, sex, passenger class, ticket fare, family relationships, embarkation port and survival status.

# Dataset Source
The dataset used in this project was obtained from Kaggle.

# Analysis Performed
# 1. Data Cleaning
Inspected the data, examine missing values, and prepared the data for amnalysis.
# 2. Univariate Analysis
Explored age, fare, and survival distributions to understand the characteristics of the passengers.
# 3. Bivariate Analysis
Investigated survival patterns by sex, passenger class, age, fare, family relationships, and embarkation port.
# 4. Multivariate Analysis
Used correlation analysis and comparisons involving passenger class, sex, age, and survival status to explore relationships between variables.

# Key Findings and Insights
The analaysis investigates differences in survival outcomes across passengere groups and explores relationships between demographic characteristics, travel conditions and survival. The accompanying notebook contains the detailed visualizaton and observations.

 The project demonstrate the use of Python for data cleaning, exploratory data analysis, visualization and insight generation.
